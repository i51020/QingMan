## 四、公共 API 现状（为什么不做 `1.0.0`）

**公共 API = 三件，全部机器可判**：

| # | 契约 | 载体 | 现状 |
|---|---|---|---|
| 1 | HTTP `/api/*`：路径 / 请求字段 / 响应字段 / 错误码语义 | `server/routes.py` + `shared/error-codes.json` | 13 组端点、70 码，均已定型但仍可改 |
| 2 | 编辑态文档 `editorDocument` | `shared/schema.json` | 有 schema 守卫，字段仍可增改 |
| 3 | 模板格式 `.md` ↔ `.json` 双向等价 | `templates.py` + `dtree_core.render_md_template` | 双向等价有断言，格式仍可演进 |

**版本策略（§P0-6 M9）**：`0.y.z` 阶段 —— 契约变更（破坏或兼容新增）升 **MINOR**；只改实现升 **PATCH**；
纯样式/文案/文档不升版。**当前 `V0.0.55` 处于 `0.0.x` 流水号尾段，下一个契约变更将是 `V0.1.0`。**

**为什么现在不宣布 `1.0.0`**：`1.0.0` 的语义是「公共 API 稳定，此后破坏性变更必须升 MAJOR」。
当前唯一消费者是**本机使用者本人与接续会话**，没有外部依赖需要被保护；提前冻结只会让每次改字段都背上
「升 MAJOR / 维护兼容层」的义务。**冻结的触发条件**（出现任一即升 `0.1.0` → 再谈 `1.0.0`）：
① 出现第二个使用者；② 有脚本 / 外部工具依赖 `/api/*`；③ 模板库作为资产对外分发。

## 六、已知边界（**有意**，不是缺陷）

| 边界 | 说明 | 为何保留 |
|---|---|---|
| 编辑态上限 **20000 节点** | `config.MAX_EDITOR_NODES` | 防误导入巨型树拖死页面；实测 5000 行仍可用 |
| 非法拖拽落点**完全静默** | 禁止光标 + `drop` 不触发 + 不弹提示 | 与「拖进自身子树」既有行为一致；要「解释为什么不能放」需新增 UI 语义 |
| 模板行 `⋮` 为 **27×27**（非设计稿 22×22 圆） | `V0.0.54` 裁定 A | 27px 点按目标更大；22px 低于触控下限，本项目不做触屏 |
| 「目标位置」为**纯图标**按钮 | 裁定 A | 与「工作区按钮图标化」整批一致；语义走 `aria-label` + `title` + 占位提示三通道 |
| 仅 **Windows + 鼠标键盘** | 环境约束 | 触屏 / macOS / Linux 本机无法验证，不写承诺 |
| 超长路径依赖系统开关 | 实测 40 层 / 547 字符可建成（本机长路径已启用） | 不额外加壳处理；换机若失败属系统设置问题 |

## 七、明确不做（并给出触发条件，避免反复讨论）

| 不做 | 理由 | 何时才做 |
|---|---|---|
| 安装包 / 代码签名 / 自动更新 | 单机绿色目录型工具：`start.bat` + `src/` 即全部，目录搬走数据跟着走；签名需证书年费 + 审核，打包会引入 30 MB 级产物与杀软误报 | 若要给**非技术用户**分发 |
| 跨平台 | 无法验证 = 不承诺（本机只有 Windows） | 有可实测的目标机 |
| 触屏 / Pointer Events 重写 | 同上，且 UI 尺寸按鼠标标定 | 有触屏设备实测 |
| `1.0.0` 冻结 | 见 §四 | 出现外部消费者 |
