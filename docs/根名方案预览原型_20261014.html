依据：《项目手册》§十一 #3（A=保持+理清 / B=参考文件式「不建根」勾选 / C=根名即树根）· §十四 #7。本页不入 src/ 交付，随文档存档。

现状症结（代码实测，非推断）

  • 树编辑区自带一个根节点（默认名 sample.root），不可改名（main.js L527 拦截）。
  • 参数区另有「根文件夹名」输入框（#inRoot）；生成时只认它 → base = target/root，留空则直接写入 target（routes.py L140-148）。
  • 树编辑区的根节点名完全不参与生成；但提示文案却称「根节点名称由『根文件夹名』决定」——与实现不符。
  • 结果：界面出现两个「根」（树区的 / 参数区的），语义割裂 —— 三个方案即围绕「如何统一」展开。
