## 二、目标模型（三层）

```
① 内置层   templates/P0_空白项目模板.json        ← 随工具交付，唯一内置（只读）
                        │
② 用户层   <用户绑定目录>  (QM_TEMPLATES_DIR)     ← 唯一可写模板库（读写）
                        │
```

**运行态模板库 = ① 内置 P0 ∪ ② 用户绑定目录**（同名时用户层优先，并在列表标注来源层）。

```

├─ templates/
│  └─ P0_空白项目模板.json            # 仅此一套内置
├─ templates-pack/                    # 新增：独立可分发包（不进 store MANIFEST）

└─ src/
```

## 三、`.md` 树语法（严格、可解析、可往返）

**设计原则**：**单向无歧义**（任一台法 `.md` 只能解析出唯一嵌套字典；任一嵌套字典只能产出唯一 `.md`），且与既有 `toPlainTree` 的「目录=dict / 文件=字符串」**一一对应**。

### 3.1 文法（BNF 式）

```
doc        ::= title? desc? item*
title      ::= "# " <模板名> "\n"                 # 可选；缺省取文件名 stem
desc       ::= ("> " <行> "\n")+                   # 可选；紧跟标题的引用块，拼接为 description
item       ::= indent "- " name "/"? "\n" body?
indent     ::= ("  ")*                             # 每级 2 空格，禁止 Tab
name       ::= <单段名>                             # 不含 / \ : * ? " < > | ，≤120 字符
body       ::= fenced?                             # 仅文件可有；目录不可带 body
fenced     ::= indent "  " "```" <info?> "\n" <原样行>+ indent "  " "```" "\n"
```

**判定规则（顺序即优先级）**：
1. `# ` 行（文档内首个）→ **模板名**；其后紧邻的 `> ` 块 → **描述**。
2. `- ` 行 → 节点；**缩进每 2 空格一级**。
3. 节点名**以 `/` 结尾** → **目录**（权威判据）；否则 → **文件**（默认正文 `""`）。
4. 文件下方**再缩进 2 空格**的围栏块 → **文件正文**（info string 忽略）；目录下的 `- ` 行 → 子节点。
5. 其余行（顶级空行/注释）忽略；顶级非 `#`/`>`/`-` 文本 → 解析失败（`templateBadJson` 语义复用）。

### 3.2 示例

```markdown
# 实拍短视频项目

> 项目类 P1 · 实拍短视频：从选题到成片交付。

- 日志/
  - 会议纪要/
- 项目原始资料/
- 项目管理/
  - 项目章程/
- 交付物/
- 说明文档.md
  ```
  # 项目说明
  - 用途：实拍短视频项目起点
  ```
- 空白目录/
```

### 3.3 往返与边界

| 场景 | 规则 |
|---|---|
| 目录名含 `/` | 不可能 —— `validate_segment` 已禁 `/`，故「尾部 `/` = 目录」无歧义 |
| 正文含 `- ` 行 / ``` 行 | 一律包在围栏块内 → 不参与节点解析 |
| 正文含围栏定界符本身 | 解析器按**首个等缩进 ``` **闭合；如需真含，写入端改用四个反引号定界（写端保证） |
| 空目录 | `- 名/` 无子项 |
| 缩进非 2 的倍数 / 用 Tab | 解析失败（严格） |
| 名称含 `📁` 前缀（解析端兼容） | 接受并剥离；**写端一律用尾部 `/`**（规范形） |
| 节点数 / 深度超限 | 复用 `MAX_NODES` / `templateTooManyNodes` |

| 方法 | 路径 | 语义 |
|---|---|---|

## 五、配置持久化

**优先级**：`QM_TEMPLATES_DIR`（env）> settings 文件 > 默认 `templates/`。

**settings 文件位置**（按可写性择优，取首个成功者）：
1. `%APPDATA%/QingMan/settings.json`（推荐，用户级、跨升级保留）
2. `<PROJECT_DIR>/.qingman/settings.json`（便携态兜底）

内容最小化：`{ "schemaVersion": 1, "templatesDir": "<绝对路径>" }`。写入用**原子写**（复用 A-P3-2 的 `_tmp_sibling` 体例）。

## 八、风险与缓解

| 风险 | 级别 | 缓解 |
|---|---|---|
| 迁移 16 套时**内容保真**出错 | 高 | `pack_templates.py` 生成 `.md` 后**反向解析比对**原 `.json`（逐节点等价断言），不一致即拒绝打包 |
| 用户把绑定目录指向 QingMan 自身 / 系统区 | 高 | 拒自绑判据 + R3/R4 复用；`PUT` 前实测可写 |
| 轮询误报「目录变化」导致重渲染抖动 | 中 | 以 `file + mtime + size` 三元组为变化判据；`visibilitychange` 暂停 |
| `.md` 往返非幂等（正文含围栏/`- `） | 中 | 写端动态升级围栏长度（4 反引号）；往返对单测覆盖 |
| `tkinter` 在精简环境缺失 | 低 | 探测失败 → 降级「手动粘贴路径」输入框 |
| 内置 P0 与用户库同名冲突 | 低 | 用户层优先 + 列表标注 `source` |
