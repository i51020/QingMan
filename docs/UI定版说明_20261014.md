## 一、定版纪律

| # | 纪律 | 落地方式 |
|---|---|---|
| 1 | 设计稿**提案样式块**是真身唯一增量来源 | 逐组移植、逐组验证；不做即兴发挥 |

### 2.2 B 组 · 应用内弹层

| 层 | 元素 | 形态 | 内容来源 |
|---|---|---|---|
| 遮罩 | `#scrim` | 全局单例 | — |
| M1 服务设置 | `#dlgService` | `modal-md` | 地址（`#svcAddr` = `window.location.origin`）+ 测试连接（`#btnSvcTest`）+ 说明 |
| M2 帮助 | `#dlgHelp` | `modal-lg` | 左目录 `#dlgHelpToc` + 右正文 `#dlgHelpDoc`，由 `js/ui/help-doc.js` 渲染 |
| M3 支持 | `#dlgSupport` | `modal-sm` | 赞赏码 `assets/sponsor-wechat.png` + 说明 |
| M4 语言 | `#popLang` | `popover` | `js/ui/lang-picker.js` 的 `createLangMenu()` 填充 `menu-item[role=menuitemradio]` |
| M5 更多 | `#popMore` | `popover` | 状态行 `#popMoreStatus` + 服务 / 支持 / 帮助三入口 |
| M6 皮肤 | `#popSkin` | `popover` | `js/ui/skin-picker.js` 按 `swatch` 渲染 `.sw-card` 到 `#skinGrid` |

**弹层物理**：

- `modal`：居中 + 遮罩 + 焦点陷阱 + `#app` 置 `inert`（背景不可点）；
- `popover`：贴触发器下沿 + 无遮罩 + 点外部关闭；
- 三条关闭路径统一由 `ui/layer.js` 接线；`hidden` 由 `.layer[hidden]` 提升到真正 `display:none`
  （否则只是 `opacity:0`，仍可点）。

**z-index 阶梯**：`#scrim` 900 → `.layer` 1000 → `#ctxMenu` 1100 → `.toast-host` 1500。

**弹层必须置于 `#app` 之外**：`#app` 在弹窗打开时被置 `inert`，弹层若在其内会一并失去交互。

**为什么帮助 / 支持改弹窗**：主界面内存里可能正握着一棵尚未落盘的目录树，
**同标签跳转会丢编辑态**（见 `docs/项目约定.md` §P0-3）。弹窗在原页面就地开合，不打断编辑。

## 六、第 2 步落地（V0.0.40@r2 · E 组「目标位置选路径」）

**路线**：**纯前端复用**（用户裁决）—— 后端零改动，复用 V0.0.38 的 `POST /api/templates-dir/pick`。

| # | 文件 | 改动 |
|---|---|---|
| 1 | `src/web/index.html` | `#inTarget` 外裹 `.field-inline`，新增 `button.btn.btn-ghost.btn-mini#btnPickTarget`（`data-i18n` + `data-i18n-title` 双属性） |
| 2 | `src/web/css/layout.css` | 新增 `.field-inline`（输入框与按钮同行；输入框 `flex:1 1 auto; min-width:0`）—— **无裸色值 / 不感知皮肤**（过 7c · 7d） |
| 3 | `src/web/js/main.js` | 新增 `chooseTargetDir()`（复用 `api.pickTemplatesDir()`，降级同 `chooseTemplatesDir` 走 `window.prompt`）+ `applyTargetDir()`（写输入框 + 刷新摘要行）；接线 `#btnPickTarget` 时 `preventDefault()` |
| 4 | `src/web/js/i18n/*.js` | 新增 `gen.targetPick` / `gen.targetPickTip` / `gen.targetPastePrompt`（中英各 3 键，键对齐） |
| 5 | `tools/verify.py` | `REQUIRED_IDS` 增 `btnPickTarget`（关键 id 50 → **51**；校验项数仍 94） |
| 6 | `tools/browser_smoke.py` | 新断言「目标位置『选择…』按钮就位且随语言刷新」（采集 `pickTargetBtn` / `pickTargetEn` / `pickTargetZh`）→ **22 项** |
| 7 | `tests/test_browser_smoke.py` | NORMAL 增 3 字段；计数 `18→19` / `14→15`；新增 2 项回归（按钮缺失 / 文案未刷新）→ **365 OK** |

**为何在接线处 `preventDefault()`**：按钮位于 `<label>` 内，浏览器会把点击**转发**给 label 关联的输入框 —— 若不拦，原生框弹出前输入框会被顺手聚焦（收起键盘态时视觉上像「没反应」）。

**语义边界（实测，非推测）**：后端 `_ask_directory()` 是 `filedialog.askdirectory(mustexist=True)`，且**不接受 `initialdir`** —— 故点选**只能选已存在目录**，且打开时**不定位**到 `#inTarget` 现值。这是复用途经的既定代价，已记入《项目手册》§9.2-9；日后若需「定位当前值 / 允许新建不存在的路径」，再评估端点加参（B 路线）。
