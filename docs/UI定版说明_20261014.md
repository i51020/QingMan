**弹层物理**：

- `modal`：居中 + 遮罩 + 焦点陷阱 + `#app` 置 `inert`（背景不可点）；
- `popover`：贴触发器下沿 + 无遮罩 + 点外部关闭；
- 三条关闭路径统一由 `ui/layer.js` 接线；`hidden` 由 `.layer[hidden]` 提升到真正 `display:none`
  （否则只是 `opacity:0`，仍可点）。

**z-index 阶梯**：`#scrim` 900 → `.layer` 1000 → `#ctxMenu` 1100 → `.toast-host` 1500。

**弹层必须置于 `#app` 之外**：`#app` 在弹窗打开时被置 `inert`，弹层若在其内会一并失去交互。

**为什么帮助 / 支持改弹窗**：主界面内存里可能正握着一棵尚未落盘的目录树，
**同标签跳转会丢编辑态**（见 `docs/项目约定.md` §P0-3）。弹窗在原页面就地开合，不打断编辑。

### 7.1 与「另存为」的分工（为什么两者都要留）

| 入口 | 骨架来源 | 依赖编辑态 |
|---|---|---|
| 另存为（V0.0.13） | **正在编辑的目录树** | 是 |
| **新建模板**（V0.0.41） | 空白 / 库中任一模板 | **否** |

### 7.2 两处设计抉择

**① 起点选项取「当前模板库」，而非写死内置 P0 文件名。**
模板库是可绑定的（`QM_TEMPLATES_DIR` env > settings > 默认 `templates/`，见 `config.templates_dir()`）。若把「内置 P0」写死成 `P0_空白项目模板.json`，用户一旦把库绑到外部目录，该选项必然失效。改为「空白 + 库中每一套」后：默认态库里唯一一套就是 P0（**行为与预期一致**），换库后自动跟随。顺带规避了「JS 里硬编码中文文件名」会触发的 7b 守卫。

**② 落盘后不自动载入编辑器。**
载入会**丢弃内存里那棵尚未落盘的树**（《项目约定》§P0-3）—— 这正是 B 组把帮助 / 支持从新标签改为应用内弹窗要规避的同一类事故。故新建后只刷新列表；要编辑它，在列表里点它即可（那条路径本就有未保存确认）。

### 7.3 复用的后端契约（**零改动**）

| 端点 | 用途 |
|---|---|
| `POST /api/templates` | 落盘 `saveTemplate({name, description, tree})`；同名默认拒写（`templateExists`），用户确认后带 `overwrite:true` 覆盖且旧模板入 `templates/.trash/` |
| `GET /api/templates/<name>` | 「起点＝某模板」时取其 `tree` 作骨架 |
| `GET /api/templates` | 填起点下拉（替代写死的内置模板名） |

**空白起点的合法性已在后端核实**：`save_template` 对 `tree` 只做 `isinstance(dict)` + 规模上限，**无下限**；`count_tree({})` → `(0,0)`，故 `tree: {}` 可落盘（＝只有根节点、无子节点的模板）。

### 7.4 新增 CSS 通用类的由来

`base.css` 里原有明确约定：「日后若新增不在 `.topbar-select` 内的 `<select>`，须另配箭头」。弹窗里的「起点」下拉正是**不在顶栏**的第一例 —— 处置方式是**抽共用选择器**（`.topbar-select::after, .select-wrap::after`），而非再抄一遍箭头规则（后者迟早漂移）。
