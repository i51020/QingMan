# 皮肤可访问性契约（WCAG AA）

> 配套 `src/web/css/skins/README.md`（皮肤目录总说明）。本文件是**配对集与阈值的权威版**；
> 因 `src/**` 有**总量体积预算**（§P2 第 4 项；**V0.0.40 起 512K → V0.0.49 起 576K → V0.0.51@r9 起 640K**），完整表格**落在 `docs/`**（不计入该预算）。

## 为什么会有这份契约

皮肤变量不只是视觉取值，**还须满足对比度下限**。配对集与阈值**由组件 CSS 的真实共现反查得出**，
**不凭语义想象构造** —— 后者会产出看着很像真的**假红**（→《错误笔记》§三.58）。

由 `tools/verify.py` 的 **7d-4** 守卫逐款校验：**18 基座 × 16 配对**
（16 款皮肤 + `tokens.css` 浅 / 深块）。**基座数由 `skins.js` 注册表派生** ——
新增一款皮肤即自动 +1，**本处数字须随手同步**（V0.0.50 前误记为「17 基座 / 15 款」，见《错误笔记》§三.76）。

## 非文本配对（AA 门槛 3.0，3 组）

`--qm-accent` 在组件 CSS 里**从不作 `color`**，只作 `border-color` / `outline` / `border-left`，
故按「UI 组件边界」的 3:1 门槛校验（WCAG 1.4.11）。

| 前景 | 背景 | 用途 |
|---|---|---|
| `--qm-accent` | `--qm-bg` | 描边 · 页底 |
| `--qm-accent` | `--qm-surface` | 描边 · 面板 |
| `--qm-accent` | `--qm-accent-soft` | 描边 · 软底 |

## 改皮肤时的三项连带

1. 改任一 `--qm-*` 取值 → `verify` **7d-4** 会重算上表，**不达标即 FAIL**。
2. `swatch[0]`（背景）与 `swatch[1]`（强调色）须与 CSS **逐值一致** —— `verify` **7d-3**。
3. 下拉按 `swatch[0]` 明度**亮 → 暗**排序 —— 顺序由 `browser_smoke` **独立复算**锁定（V0.0.39）。

⚠️ **不要拿「墨色」当底色** —— `--qm-accent-ink` 是**前景**语义（暗色皮肤下为浅色），
当 `background` 用会与 `--qm-on-accent` 撞车（→《错误笔记》§三.57）；按钮悬停底用 `--qm-btn-bg-hi`。
