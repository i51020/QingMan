使用说明

青蔓 QingMan 是一个本地离线运行的目录结构设计工具：可视化编辑目录树，一键在磁盘上生成真实目录。

快速开始 界面说明 目录树操作 快捷键 安全说明 版本与关于 免责声明

快速开始

  1. 双击项目根目录的 start.bat 启动本地服务
  2. 浏览器自动打开，确认顶栏显示「后端已连接」
  3. 在左侧「模板工作区」选一套模板直接载入，或在中间自行编辑目录树
  4. 填写「目标位置」，先保持「仅演练」勾选试跑一次
  5. 确认结果无误后取消勾选，点「一键生成」真实落盘

界面说明

  • 左栏「模板工作区」——列出模板库中的模板，点击即载入；标题右侧三枚按钮是「新建模板 / 导入模板 / 多选」。多选进入选择模式后，行前出现复选框，可批量导出（打成一个 ZIP）或批量删除（移入 templates/.trash/）。每行行尾还有一个 ⋮，点开是「载入 / 重命名 / 复制 / 导出 / 删除」（与右键菜单同一套）。
  • 中栏操作带里的「另存为模板」——把当前目录树存成模板库里的一套新模板。它和左栏模板行的「导出」不是一回事：后者是把模板库里已存的那份文件原文取出来下载。
  • 中栏「目录树工作区」——顶部是生成参数与操作带，主体是目录树。
  • 参数区左上角可点开／收起：收起后只留一行摘要（目标位置 · 根名 · 演练或写盘），当前设定仍一眼可见。
  • 右栏「属性工作区」——选中节点的名称、类型、路径、深度与统计；下方显示生成结果。

目录树操作

  • 单击节点选中，右栏属性面板同步刷新
  • 「新建子节点」在选中的目录下增加一个子目录
  • 「重命名」修改节点名称；根节点名称由「根文件夹名」决定，不在此处改
  • 「删除」移除选中节点及其全部子节点（有二次确认）
  • 「全部展开 / 全部折叠」批量切换层级
  • 拖拽节点到某个目录上，可把它移动到该目录下（不能移到自己的子目录里）
  • 在节点上单击右键可弹出菜单：新建子节点 / 重命名 / 删除 / 复制路径

快捷键

  • Ctrl / Cmd + S — 立即保存（跳过防抖，不等自动保存）
  • Ctrl / Cmd + Z — 撤销上一步编辑
  • Ctrl / Cmd + Y 或 Ctrl / Cmd + Shift + Z — 重做
  • Delete — 删除选中节点（有二次确认，可撤销）
  • F2 — 重命名选中节点
  • 其余键位待功能面稳定后统一约定。

安全说明

  • 后端仅监听本机回环地址（127.0.0.1），局域网内其他设备无法访问
  • 服务端做调用来源校验（Host 白名单 + Origin 严格同源 + 写操作防护头），阻断跨站页面盲发请求
  • 不收集任何数据、不上传任何信息；目录树与生成结果都只留在本机
  • 「仅演练」模式不写盘；真实生成时已存在的文件一律跳过、不覆盖，且全程不删除任何既有内容
  • 删除节点等破坏性操作均有二次确认
