2「目标位置」那颗图标钮：是否恢复可见文字

现状纯图标（.btn.btn-ghost.btn-mini.btn-ic，27×27 / 图标 15px）， 语义只在 aria-label 与 title 里 —— 要悬停才知道它干什么。 取舍点：可辨识度 ↔ 与工具栏同族的一致性（V0.0.50「I 组」把工作区 20 颗按钮全改成了纯图标）。

A · 现状（纯图标）27×27，与工具栏其余图标钮同族；不给提示时语义不可见
B · 图标 + 文字27px 高不变、宽度自适应约 64px；一眼可读，但不再是「纯图标」
C · 仅文字常规迷你钮；最易读，代价是破坏「工作区按钮图标化」的整批一致性

★ 实测（无头 Edge 量产品页面本体的 #btnPickTarget）： 这颗按钮 CSS 声明 27×27，真实渲染是 25.33×27 —— .field-inline 里 input 的小数宽度（454.67px）把按钮挤掉 1.67px （flex-shrink: 1）。本页变体 A 量得 25×27，与产品一致。
若你要的是「严格 27」，需加 flex: 0 0 auto 或 min-width: 27px —— 这与「是否加文字」是两件事，可合并做。
