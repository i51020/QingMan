现状基线（本轮盘上实测）

  • 选择模型：store 中单个 selectedId 字符串，无多选能力（main.js L202/259/270）。
  • 工具栏：[撤销][重做] │ [加子][改名][删除] │ [展开][折叠] ⋯ [生成] —— 3 个 divider 却把同属「改树」的撤销/重做与增改删分开了。
  • 检视器：单视图，属性表 + note + #genResult 三段挤在同一栏。
  • 已核实：editor.json 契约只含 schemaVersion/savedAt/root —— 选中态不落盘，故 F 的多选态纯内存、零契约影响。
