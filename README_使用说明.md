# 青蔓 QingMan · 使用说明

> 版本：`V0.3.11`　适用系统：Windows 10 / 11（64 位）　**不需要联网、不需要安装、不需要预先装 Python**

---

## 一、三分钟上手

1. **解压**整个压缩包到一个**你有写入权限**的目录，例如
   `D:\工具\QingMan`、桌面上的文件夹、U 盘。
   ⚠ 不要放在 `C:\Program Files` 下（系统会拦写入，模板库会变成只读）。
2. 双击 **`start.bat`**。
3. 浏览器会自动打开 `http://127.0.0.1:8765`（端口被占用时会自动往后找，看命令行窗口里的地址）。
4. 左侧编辑目录树 → 点「生成」，选一个**空目录**作为目标位置 → 磁盘上就出现真实目录。

关闭：直接关掉那个黑色命令行窗口即可（它就是服务本身）。

> 首次启动 Windows 可能弹「已保护你的电脑」—— 点「更多信息 → 仍要运行」。
> 原因是本程序没有购买代码签名证书，**不是**因为有病毒；源码全部在 `src/` 里，可自行审阅。

## 二、你的数据在哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 当前编辑的目录树 | `data\editor.json`（随程序目录） | 程序目录不可写时自动落到 `%APPDATA%\QingMan\data\` |
| 编辑态历史备份 | `data\.bak\` | 每次保存前自动备份，保留最近 5 份；超出的移入 `.trash\`（**不删除**） |
| 模板库 | `templates\`（默认）/ 你在界面里绑定的任意目录 | 绑定后记在 `%APPDATA%\QingMan\settings.json` |
| 应用设置 | `%APPDATA%\QingMan\settings.json` | 皮肤、语言、模板库绑定 |

**便携用法**：整个文件夹拷走 = 数据跟着走（`data\` 在包内）。
**多用户共用一台电脑**：各自解压一份到自己的目录即可；若共用同一份安装目录，
程序在目录不可写时会自动把数据放进各自的 `%APPDATA%\QingMan\`，互不干扰。

想强制指定数据位置，可在启动前设环境变量：

```bat
set QM_DATA_DIR=D:\我的青蔓数据
start.bat
```

## 三、模板

- 内置 **1 套空白模板**（`P0_空白项目模板`），另有 **16 套业务模板**在 `templates-pack\` 里，
  可在界面「模板」面板逐个导入。
- 模板支持两种等价格式：`.md`（可读、可直接用文本编辑器改）与 `.json`。**导入时两种都认**。
- 「导入」会做全量校验后**重新渲染规范化**，不是简单复制文件。
- 删除模板**不进回收站以外的地方**：移入 `templates\.trash\<时间戳>\`，可人工找回。

---

## 三之二、模板：自带一张，其余按需下载

程序**只自带一张空白模板**。16 套业务模板放在**单独的模板包压缩包**里（不随程序附带），需要时再取：

1. 拿到模板包压缩包（`QingMan-模板包-<版本>.zip`），**全部解压**到模板库目录。
2. 模板库目录默认是**程序目录下的 `templates\`**；不确定时可开「服务设置 → 打开模板库目录」。
3. 回到主界面等两三秒，模板列表会自动刷新出来（也可以重新打开程序）。
4. 解压进去的 `.json`、`.md` 两种都认 —— `.md` 可以直接用文本编辑器看和改。

**导入同名模板**会先问你是否覆盖；覆盖后旧模板被移入 `templates\.trash\`，仍可找回。
**导出**时右键模板，可选 `.json`（便于再导入）或 `.md`（便于阅读、放进版本库）。

## 三之三、换肤与语言

- **换肤**：点顶栏右侧的调色板按钮，16 款任选，选过会记住。皮肤只改配色、**不改布局**，按钮位置不会变。
- **换语言**：在「更多」菜单里切换，默认跟随系统，切换立即生效。
- 两者都不需要重启；若已生成桌面快捷方式，换肤后图标会自动更新（程序保持运行即可）。

## 四、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 双击后窗口一闪而过 | 检查是否**只**复制了 `start.bat`；必须连同 `src\`、`runtime\` 一起解压 |
| 提示「未检测到 Python」 | 说明 `runtime\` 目录缺失（解压不完整）。重新完整解压，或安装 Python 3.8+ |
| 浏览器没自动打开 | 手动访问命令行窗口里打印的地址（如 `http://127.0.0.1:8766`） |
| 端口 8765–8775 全被占用 | 关掉其他实例，或设 `set QM_PORT=9000` 再启动 |
| 「选择目录」按钮提示不可用 | 精简版运行时缺图形库时的降级：直接在输入框粘贴路径即可 |
| 生成时提示目标不可用 | 目标必须是**空目录**且**不是系统目录**（程序对四类黑名单有硬拦截） |
| 杀毒软件报毒 | 未签名的自解压脚本易被误报；可把整个目录加入信任区 |

## 五、安全边界（设计如此，不是限制）

- 服务**只监听 `127.0.0.1`**，局域网内其他机器访问不到。
- 所有写操作要求同源 + 自定义头（`X-QingMan`），跨站页面无法盲发。
- **永不删除文件**：删除模板/备份一律移入 `.trash\`；生成目录时只新建、不覆盖已有文件。
- 单文档节点上限 20000，防误导入巨型树把页面拖死。
- **只防“别的网站”，不防“同一台电脑上的其他程序”**：本地服务没有登录口令，
  共用电脑时请各自使用自己的 Windows 账户；程序目录也不要放在所有人可读的公共盘。

---

## 六、升级与卸载

- **升级**：把新版本解压到**另一个**目录，只把旧目录的 `data\` 与 `templates\` 复制过去。
  （直接覆盖旧目录也能用，但保留旧目录更安全。）
- **卸载**：直接删除整个文件夹；若用过 `%APPDATA%\QingMan\`，按需一并删除。
  程序**不写注册表、不装服务、不留后台进程**。

---

## 七、版本与回退

- 当前版本见 `VERSION` 文件，界面「帮助」里也显示。
- 版本号遵循语义化版本：`V0.1.0` 起，**契约变更升 MINOR、仅实现修复升 PATCH、纯样式不升版**。
- 需要回退：把旧版本文件夹换回来即可（数据格式向前兼容，旧版本可能不认新字段，但不会破坏文件）。
