## 一、命名口径（重要）

| 项 | 做法 |
|---|---|
| **目录名** | **全部中文**（如 `项目管理`、`专业工作区`、`学习与输入`） |
| **模板名** | 中文，**不含** `P0`–`P9` / `S2`–`S8` 编号前缀（文件名保留前缀以便对照文档章节） |
| **说明文件名** | 中文（`说明文档.md`；S8 为 `库说明.txt`） |
| **品牌与产品名** | 保留原文（如 `Photoshop`、`DJI Studio`、`Obsidian`、`COLMAP处理`），因为中文语境下也这么称呼，改译反而不好找 |
| **规则关系** | 文档的 `Title_Snake_Case` 规范仅作参考；本库按你确认的口径改为中文，不受该规范限制 |
| **序号前缀** | 未使用（沿用文档「不使用序号前缀」的口径） |

### 目录数口径说明（非错误）

文档 §6.1 对项目类的口径是「项目级横向职能 14 个 + 专业工作区内**除专业根以外**的目录」。
本库模板**包含专业根**（如 `专业工作区/实拍短视频/`，文档 §1.4 注明完整运行专业脚本时会生成它），
因此项目类比文档统计多 1：P1 29→30、P2 43→44、P3 54→55、P4 37→38、P5 43→44、
P6 22→23、P7 21→22、P8 22→23、P9 35→36（P0 无专业根，仍为 14）。
独立系统 S2–S8 与文档统计完全一致。

### 与文档的其他差异

- **不生成清单文件**：文档中的 `.<script>_manifest.json` 是脚本运行产物，非目录结构，模板不预置。
- **额外说明文件**：S3 含 `共用资产/调色LUT/调色LUT命名建议.md`，S8 含 `文档/短链接登记表.txt`，与文档 §8.2 / §8.7 一致。

## 三、导入方法一：可视化界面（推荐，全鼠标）

1. 双击打开 `目录树可视化管理器.html`（Chrome / Edge）
2. 左侧「模板库」→ 点「导入 JSON」
3. 用记事本打开任一 `.json` 文件，全选复制，粘贴进输入框，点「导入」

**批量导入（一次性装入 17 套）**：
左侧「存放位置」→「选择文件夹」→ 选中本文件夹 →
17 个模板会**全部自动读入**模板库，无需逐个粘贴。

> 导入后模板名会原样保留（重名时自动加 `-2`、`-3` 序号，不覆盖）。

## 四、导入方法二：命令行技能

把本文件夹内 17 个 `.json` 复制到模板库目录：

```bash
# 默认模板库位置
~/.dtree/templates/

# 或用环境变量自定义
export DTREE_HOME=/你的路径
mkdir -p "$DTREE_HOME/templates" && cp *.json "$DTREE_HOME/templates/"
```

随后即可：

```bash
python scripts/dtree.py list                      # 查看 17 套模板
python scripts/dtree.py show P1_实拍短视频项目     # 预览结构
python scripts/dtree.py create S2_个人知识库 ./我的知识库 --dry-run   # 先演练
python scripts/dtree.py create S2_个人知识库 ./我的知识库             # 真实创建
```

## 五、JSON 格式说明

每份模板为标准结构，可直接被工具读取：

```json
{
  "name": "模板名（中文）",
  "description": "中文说明",
  "updated": "2026-10-03",
  "tree": {
    "目录名": { "子目录": {} },
    "文件名.md": "文件内容"
  }
}
```

- 值是 `{}` 对象 → **目录**
- 值是字符串 → **文件**（字符串即文件内容）
- 目录名支持中文，仅禁止 `\ / : * ? " < > |` 等文件系统非法字符

## 分发包布局（2026-10-11 · V0.0.37）

本目录（`templates-pack/`）是**独立可分发的模板包**，与工具本体解耦：

| 位置 | 内容 |
|---|---|
| `templates/`（工具内置） | **仅** `P0_空白项目模板.json`（唯一内置空案例） |
| `templates-pack/`（本目录） | 16 套业务模板的 **`.md`（主）+ `.json`（等价）**、`P0_空白项目模板.md`（与内置 `.json` 同源）、本说明、`pack.manifest.json`（校验清单，含逐套 sha256） |

- **`.md` 为主**：AI / Agent / Skill 可直接读取；`.json` 为等价副本，供工具直读。
- **重新生成/校验**：`python tools/pack_templates.py`（默认校验 + 写清单 + 打 zip）；
  `--check` 只校验不写盘；`--zip <路径>` 覆盖 zip 落点。清单 `digest` 与 zip sha256 均可复算。
- **分发件**：`QingMan-模板包.zip`（由脚本确定性构建，不入版本库）。
- 工具内模板**一律经「目录绑定 / 导入」载入**，不再内置业务模板。
