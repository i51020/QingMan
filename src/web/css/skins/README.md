# 皮肤目录（§P0-3 L5）

存放**皮肤变量覆盖文件**，一个皮肤一个 `.css`。当前内置 **16 款**（`s01-cream-pink` … `s16-warmgray-amber`；
**出厂默认 S16「暖灰·琥珀」**），
注册表在 `src/web/js/i18n/skins.js`（`cid` → 文件 / 取词键 / 明暗 / `swatch`）。

## 契约

| 项 | 约定 |
|---|---|
| 皮肤是什么 | **一组 `--qm-*` 变量的覆盖值**，不是一整套组件样式 |
| 文件位置 | `src/web/css/skins/<name>.css`，`<name>` 即 `localStorage['qm.skin']` 的值 |
| 装载方式 | `i18n/index.js` 的 `applySkin()`：按 `qm.skin` 动态注入 `<link id="skinLink">`。**产品始终有一套完整配色，不存在「无皮肤」态** —— `getSkin()` **恒返回非空**（无偏好或偏好非法都回落到出厂默认），故样式表总会被装载 |
| 组件 CSS | **不得感知皮肤**（不写 `.skin-dark .btn`、`[data-qm-skin=…]`），只消费变量；由 `tools/verify.py` 把关 |
| 变量来源 | 变量须先在 `tokens.css` 定义；皮肤文件只做**重新赋值**，不得引入新变量名 |
| 深浅主题 | 系统偏好由 `tokens.css` 处理；皮肤用于**显式指定**一套配色 |

## 可访问性契约（WCAG AA，V0.0.39 起）

皮肤变量还须满足**对比度下限**：**16 组配对**（13 文本 AA **4.5** + 3 非文本 AA **3.0**）
由 `verify.py` **7d-4** 逐款校验（**17 基座 × 16 配对**）。⚠️ **勿拿「墨色」当底色** ——
`--qm-accent-ink` 是**前景**语义，当 `background` 会与 `--qm-on-accent` 撞车；悬停底用 `--qm-btn-bg-hi`。
**完整配对表与三项连带见 `docs/皮肤可访问性契约.md`**。

## 三阶落差规则（V0.0.46 立规 · V0.0.47 收口全域 · 落在 `--qm-surface-2`）

`--qm-surface-2` 是**填充色**（`.btn` / `input` / `select` / `.tpl-badge` / `.help-qr` 等，**共 21 处**
`var(--qm-surface-2)` 消费点：`base.css` 5 / `layout.css` 8 / `soft.css` 7 / `help.css` 1），
**不承担凸凹语义** —— 凸凹由 `soft.css` 的 `--qm-tap` / `--qm-tap-in` 阴影 + 1px 描边承担。
故它与 `--qm-surface` 的 **CIE L\* 落差必须小**：

- **幅度**：`ΔL*` 绝对值 **≤ 1.5**（目标 ≈ 1.0）。
- **方向**：浅色区制（面板 L\* > 50）取**负**（次级面略暗于面板）；深色区制取**正**（次级面略亮于面板）。

实测 2026-10-15（V0.0.46）：15 款落在 **ΔL\* −1.37 ~ +1.16**。原深色 4 款（S03 / S07 / S12 / S14）
落差 +3.79 ~ +5.45 **过大**，已收窄至 +1.16 / +0.89 / +0.95 / +0.90。

**V0.0.47 收口全域**：本规则此前只查 15 款皮肤，但 `tokens.css` 的浅 / 深两段**同是**
`--qm-surface-2` 的取值来源 —— `help` / `support` 两页没有皮肤选择器，`tokens` 默认值**直接生效**
（两页共 13 处消费点，含 `.help-qr`）。原值浅 **+2.49**（**方向与 11 款浅色皮肤全相反**）、
深 **+3.70**（**超 1.5 上限**），已按「取面板同色相降 / 升一档」归位至 **−1.04 / +0.97**
（浅 `#ffffff → #f3f5f8`、深 `#232a32 → #1f242b`；`--qm-surface` 面板色一律未动）。
判据与 16 款皮肤**同一套**，改由 `7d-8` 一并把关 —— 共 **18 个配色面**（16 款 + tokens 浅/深）。

由 `tools/verify.py` **7d-8** 逐面把关。⚠️ 判据用 **CIE L\***（感知均匀），**不可**用相对亮度差 ΔL
（后者不可跨明暗比较 → 会得出「深色皮肤落差更小」的反向结论）。裁定过程与逐款实测见
`docs/背景三阶对照_20261015.html`。

## 写一个皮肤

```css
:root { --qm-bg: #eceff4; --qm-surface: #f6f8fb; /* 只列想改的，其余沿用 tokens.css */ }
```
控制台 `localStorage.setItem('qm.skin', '<name>')` 后刷新即生效（清空恢复默认）；键名固定 `qm.skin`，
与 `qm.lang` 一并由 §P0-3 L6 约定。
